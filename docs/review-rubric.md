# レビューの採点表（第 4 版）

Apple Design Awards の 6 部門を、このアプリ（家族 3 人がパリ旅行のためにフランス語を学ぶ Web アプリ）向けに言い換えたもの。
レビュー担当は、スマホ幅（390px）とデスクトップ幅の画面写真とコードを見て、部門ごとに 1〜5 点を付ける。

| 部門 | 見ること | 5 点の姿 |
|---|---|---|
| 楽しさ (Delight and Fun) | 開くのが楽しみか。演出・ご褒美・手応え | 駅に着く・扉が開く・スタンプが押される瞬間が気持ちよく、毎日開きたくなる |
| 革新性 (Innovation) | ありきたりの単語帳でないか | 旅程・家族・路線図が学び方そのものになっていて、他で見たことがない |
| 操作感 (Interaction) | 迷わず、触って気持ちいいか | 次にやることが常に 1 つ。押せる所が大きく、反応が速く、戻れる |
| 誰でも使える (Inclusivity) | 母も弟も使えるか。アクセシビリティ | 大きな文字、色だけに頼らない、読み上げ対応、動きを減らす設定、片手で届く |
| 社会への良い影響 (Social Impact) | 家族で一緒に学び、旅を良くするか | 家族の進み具合で励まし合え、旅先で本当に役立つ（オフライン・指さし・SOS） |
| 見た目 (Visuals and Graphics) | 一貫した美しさ、細部 | モチーフ（メトロ駅のタイル・路線図・駅名標）が全画面で一貫し、余白・文字・色の細部が整っている |

## 合格の基準
- 6 部門すべて 4 点以上、平均 4.5 点以上
- 「見た目」は 5 点（利用者から「デザイン賞を取れるくらいおしゃれに」と求められているため。2026-10-24 から）
- 採点は実在の Apple Design Award 受賞作（Flighty、Duolingo、Headspace、(Not Boring) など）と並べたときの水準で付ける
- 「壊れている・読めない・押せない・はみ出す」などの致命的な指摘が 0 件
- レビュー担当 2 者（Codex と Claude のレビュー担当）の両方が合格を出す

## レビューの出し方
- 部門ごとの点数と理由（1〜2 文）
- 直すべき点を、重要度（致命的 / 高 / 中 / 低）つきで、画面と場所を具体的に
- 合格 / 不合格
