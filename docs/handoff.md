# 引き継ぎメモ（Claude Code ⇄ Codex）

## 現状（2026-10-25、デザイン第 6 版 « Promenade illustrée » を枝 design-v6-research で作業中。公開は第 5 版＋Maison）
- 家族 3 人（本人・母・弟）が各自のスマホで使う、パリ旅行向けのフランス語学習アプリ。手組みの静的 HTML/CSS/JS、ビルド不要（`python -m http.server` で `index.html`）。
- 構成: メトロの路線を進むコース（13 駅＋終点 PARIS、駅ごとにレッスン・読み方・会話、スタンプ）、今日の切符（レッスン・復習・予行演習／苦手／聞き取り）、フレーズ（11 場面 189 文）、練習（復習カード・聞き取り・数字・苦手・会話の練習・読み方）、しおり（旅の 4 日・困ったとき・保存した表現・住所カード）、家族（進み具合をリンクで共有・応援・この端末を使う人・設定）。
- 記録は端末ごと・人ごと（localStorage `fr3:p:<id>:<key>`）。クラウドなし。家族の進み具合は `?card=FR1.…` のリンク、招待は `?trip=YYYY-MM-DD&days=4`。
- PWA（sw.js は tools/gen-sw.mjs が生成、オフラインで動く・ホーム画面に置ける）。音声は edge-tts の data URI 517 本。駅の絵 15 枚（パリを描いた名画、Wikimedia Commons のパブリックドメイン、WebP 計約 2.4 MB、オフラインにも保存）。
- 検証済み: `node --test tests/*.mjs` 24 pass、`node tools/validate.mjs` OK、`node tools/gen-sw.mjs --check` 一致、Playwright の画面写真（モバイル・ダーク・デスクトップ 62 枚）でページエラーなし。WebKit（iPhone 13 の画面）ではじめにの日付欄が画面に収まることを確認。
- 未検証: 実機（iPhone Safari／Android Chrome）での音声認識・tel: リンク・ホーム画面追加・読み上げ（VoiceOver／TalkBack）・大きな文字モード・動きを減らす設定。大使館の電話番号（01 48 88 62 00）は出発前に要確認。
- 公開済み（2026-10-24）: https://junyeol928-hash.github.io/paris-french/ （GitHub Pages、main のルート）。リポジトリ https://github.com/junyeol928-hash/paris-french 。過去の履歴には公開できない個人情報があるので、公開側は現在の中身だけをまとめた別の履歴（手元の `init` とはつながっていない）。

## 変更内容
- 第 3 版で全面作り直し（人ごとの記録、メトロの路線のコース、家族機能、PWA、発音チェック、会話ロールプレイ）。デザインは docs/design.md。
- ADA 基準のレビュー（docs/review-rubric.md）を 5 回実施し、指摘を反映（第 3 回: A 3.83 / B 3.5、第 4 回: A 4.33 / B 4.0、第 5 回: A・B とも 4.5 で合格）。合格後に余裕を持たせる仕上げ（答えた後のずれ、復習カードと会話の位置など）も反映済み。
- デザイン第 4 版（2026-10-24〜25）: 駅の壁に場面の写真ポスター、家族の路線が PARIS で合流する図、レッスン中も路線の進み具合と小さな駅名標、練習は乗り換え案内の板、見せる画面は紺のホーロー板、到着証明書はパスポートの紙。利用者の「デザイン賞を取れるくらいに」を受け、採点表に「見た目は 5 点」を足して Codex と Claude で 5 回レビュー。第 5 回で両者とも合格（平均 4.5、見た目 5、致命的 0）。
- デザイン第 5 版（2026-10-25、枝 design-v5）: 利用者の「ほとんど変わっていない。もっとプロの作品のように、パリっぽく、芸術作品風に」を受け、試作 3 案から「企画展ポスター」を選んでもらい全面改修。駅の写真を印象派などのパリの名画に替え、ホームと到着は名画を上いっぱいに大きな Bodoni の斜体の駅名と解説札、紙の地と墨の罫（図録の頁）、課題の画面の上にも駅の絵の帯（空いた高さを吸う、正解で絵がふっと寄る）。覚える文は Jost、Bodoni は題だけ。Codex と Claude でレビューを繰り返し、Claude は第 9 回（文字と UI の仕上げ後）で合格（平均 4.5、見た目 5）。Codex は利用上限で止まり、利用者の判断で待たずに公開（PR #5、2026-10-25）。Codex が戻ったら同じ画面一式で再審査してよい。
- 高級感の仕上げ « Maison »（PR #7、2026-10-25 公開）: 差し色を真鍮の金だけに（路線色は自分の印だけ）、主なボタンは和文＋斜体の仏語、音声とマイクは墨の丸に金の細い輪、進み具合や正誤は細い線、紙の粒子を画面全体に 1 枚。Claude レビュー第 11 回で合格。
- 不具合の修正: 色の選択肢を路線番号の順に、iPhone で日付欄がはみ出す、汎用 .empty の余白がスタンプの空き枠を縮めていた、家族のお知らせが後から加わった家族に出なかった、応援の共有を中断するとお知らせが消えた。
- 個人情報の検査語は `tools/private-words.txt`（git 管理外、1 行 1 正規表現）に移した。無いと validate はその検査を飛ばして注意を出す。

  - 残り: Codex の利用上限（10:25 解除）待ちで、挿絵 m-lire（白紙の本が「書く」に見える、練習の挿絵と重複）と m-carte（アルバムに見える）の描き直し（指示は scratchpad の gen/v4/prompt.md と同内容: 公園で新聞を読む紳士／チョークの絵の黒板、花と金の飾りなし）と、Codex の 3 回目の審査。

## 次に依頼すること
- 第 6 版: m-lire・m-carte を描き直して検品 → 画面写真一式で Codex と Claude の審査 → 両方合格したら PR でマージして公開。
- 以後の作業は origin/main から枝を切り、PR でマージすると数分で Pages に出る（sw.js を作り直すと、家族の端末には「更新があります」が出る）。手元の `init` は個人情報を含む古い履歴なので push しない。
- 合格ラインちょうど（両者 4.5）。楽しさ・革新性・社会への良い影響を上げるには機能の追加が要る（正解の瞬間の演出、家族の進み具合の自動の同期など）。
- 実機（iPhone／Android）で、大きな文字・動きを減らす・読み上げ・音声認識・ホーム画面追加を確かめる。
