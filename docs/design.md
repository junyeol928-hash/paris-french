# デザインの決まり（第 6 版 « Promenade illustrée »）

調べたこと・手本・原則の根拠は docs/research-ui.md。

## 目的と使う人
- パリ旅行（4 日間）に行く家族 3 人（本人・母・弟）が、フランス語ほぼゼロから「旅で困らない」まで進む。
- 使う場面: 出発までの毎日 5〜10 分（家・通勤）、旅行中は指さし帳とお守り代わり（電波なしでも）。
- 母も使う: 文字を大きくできる、押せる所は大きく、迷わない一本道。日本語の場面名が先、フランス語は学ぶ文と題で大きく。

## コンセプト
**Promenade illustrée（挿絵の地図と名画をめぐる散歩）** — 家族それぞれが自分の路線（1 人 1 番号）で、駅＝場面を進む。路線は 1900 年ごろの旅行案内のような銅版画と水彩の絵地図。レッスンごとに 1 枚ずつ別の名画があり、終えると「わたしの美術館」に掛かる。
第 5 版（企画展ポスター）は「ボタン・文字・線の路線図が安っぽい、AI が作った感じ」と言われたため、UI の飾りを減らし、絵の質で見せる方向に変えた。

## モチーフ
- 絵地図: 生成した 1 枚の街の絵（assets/img/il/map.webp）に、14 駅の円い挿絵（m-<駅>.webp）を置く。駅名は和文、その下に斜体の仏語。今の駅は墨の輪と「いまここ」の小さな墨の札。まだの駅は挿絵の色を抜いて区別する（字は薄くしない）。駅名の後ろだけ紙の下地を敷く。
- 名画: レッスンの上の帯・到着・ホームのポスター・修了の画面に、その回の名画だけを出す。生成の挿絵を名画に重ねない（本物の油彩と挿絵は役割を分ける）。
- 紙と墨と罫: 面は紙の地（paper.webp の地紋）のまま。白いカード・色の帯・影の箱を作らず、1px の罫で区切る。
- 文字だけの操作: 主なボタンは墨の四角（角 0）に和文だけ。副は 1px の枠、さらに下は下線の文字。タブも文字だけで、選んでいる所に下線。
- 人の印: その人の路線番号の丸（メトロの路線番号の書き方）。頭文字は使わない。
- 各タブの頭: 同じ画風の場面の挿絵（v-*.webp）を低く（150px、フレーズは 112px）。

## 固定するもの（定数）
- 色: UI に差し色を置かない。色は絵から来る。
  - 地 `--bg` #F4EFE5 / #17140F、面 `--surface` #FAF6EE / #1F1B15
  - 文字 `--ink` #2B2824 / #EFE8DA、`--ink-2` #4F4941 / #D2C9B8、補助 `--muted` #756D62 / #A69C8C、罫 `--line-gray` #D9D1C3 / #3A332A
  - 金は使わない（古い `--gilt` は `--muted` に向けてある）
  - 路線色はその人の印だけ（番号の丸・題の終わりの点・スタンプ・進み具合の自分の丸）。`--line` / 文字は `--line-ink`
  - 正解 `--ok`・誤り `--ng`（色と文字の両方で示す）。SOS と緊急番号は `--ng` の赤
  - 絵地図の駅名の下地と字は、ダークでも紙色と墨に固定（地図の絵が明るいままのため）
- 文字
  - フランス語の題・ラベル: Bodoni Moda の斜体、文頭だけ大文字（*Révision*、*Taxi*）。全部大文字・字間を広げた欧文ラベルは使わない
  - 学ぶ文と数字: Jost。日本語: Zen Kaku Gothic New の 400、強調だけ 500
  - 和文の見出しの字間 0.02em。行間: 本文 1.7、見出し 1.3
  - 大きな文字モードは html を 20px。タブは 15px で 1 行、題の上限は 4rem
- 余白: 4 の倍数。画面の左右は 20px（スマホ）。絵は左右の端まで
- 角: 0。丸いのは音声・マイク・人の丸・駅の挿絵だけ
- 押せる所は 48px 以上（大きな文字モードでは 56px）

## 画面の組み方
- ホーム: 名画のポスター（駅名の大きな斜体）→ 解説札 → 学ぶ文の例 → 墨のボタン → 今日の 3 つ → 家族の知らせ（罫の行と下線の「応援する」）→ わたしの路線（絵地図）。
- レッスン: 上に進み具合、名画の帯と駅名、課題、下に固定のボタン 1 つ。正解で絵がふっと寄る。
- 修了: スタンプ → 祝いの言葉と見出し → 手に入れた名画（解説札つき）→ 次の操作。
- 家族: 各人の「いまの駅」を挿絵つきで同じ大きさに。下に「わたしの美術館」（2 列・作品名つき、絵は切り抜かず額の余白でそろえる、空の額は次の 2 枚だけ）。
- SOS・しおり: 112 は赤い大きな数字と赤い罫。表現の行は上下の罫だけで、右に音声の丸と下線の「見せる」。

## 絵
- 名画 40 枚（駅 15 枚＋レッスンごと a01〜a28）。すべてパブリックドメイン（Wikimedia Commons）。tools/make-photos.py が縮小し、data/photos.js に画家・作品名・年・出典を書く。レッスンと絵の対応は core.js の `LESSON_ART`。出典は設定の「絵の出典」。
- 挿絵（Codex の画像生成）: assets/img/il/ の m-*.webp 14 枚、v-*.webp 4 枚、map.webp、paper.webp。1890〜1910 年ごろのパリにそろえ、文字・字のような線・現代の物・エッフェル塔の重複・虫を描かない。描き直したら拡大して検品する。

## 自由にするもの（変数）
- 各画面のレイアウト、絵の切り抜き、演出
