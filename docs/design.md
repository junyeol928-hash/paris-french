# デザインの決まり（第 7 版 « Salle »）

調べたこと・手本・原則の根拠は docs/research-ui.md。第 7 版で参考にした型（Mobbin などのギャラリー約 100 画面）は下の「手本」にまとめた。

## 目的と使う人
- パリ旅行（4 日間）に行く家族 3 人（本人・母・弟）が、フランス語ほぼゼロから「旅で困らない」まで進む。
- 使う場面: 出発までの毎日 5〜10 分（家・通勤）、旅行中は指さし帳とお守り代わり（電波なしでも）。
- 母も使う: 文字を大きくできる、押せる所は大きく、迷わない一本道。日本語の場面名が先、フランス語は学ぶ文と題で大きく。

## コンセプト
**Salle（美術館の展示室）** — 名画は切らずに壁に掛け、読む物と操作は白い札（シート）に載せる。各駅・各レッスンの名画が主役で、UI は絵の邪魔をしない。
第 6 版（紙と墨と挿絵の地図）は「プロが作ったような高級感がほしい」「背景のベタ塗りをやめて、もっとおしゃれに」「名画全体が映るように」を受けて作り直した。

## モチーフ
- 壁: 画面の上（広い画面では左半分）。その絵を大きくぼかして延ばし（blur 48px・彩度 1.45・明るさ 0.5）、細かい粒子を 1 枚重ねる。色の面のベタ塗りはしない。
- 絵: どこでも `object-fit: contain` で切らずに見せる。ホームは画面幅いっぱい、タブの頭は右に小さく、レッスンは額のように中央に、達成は大きく。サムネイル（`App.medal`）だけは正方形に切る。
- 題: Bodoni Moda の正体（斜体にしない）。ホームの縦長の絵は、題を絵の上端に重ね、重なる所にだけ上から下へ薄くなる陰を敷く。
- 白い札: 壁の下端に角丸 28px の白い面が重なる（`.lip` と `.stage-body`）。白い面の中は枠線を使わず、薄い灰の面（`--wall`）で区切る。
- 主なボタンは墨の丸い面 1 つ（和文＋薄い仏語の斜体）。それ以外は薄い面。
- 解説札: 「画家　作品名（Bodoni 斜体）, 年」。`App.creditHtml`。
- 署名の動き: ホームを開いて最初の 1 回だけ、絵の一部分から全体へ引く（1.6 秒）。タブを行き来するたびには動かさない。動きを減らす設定では止める。

## 手本（何を借りたか）
- 一画面に主役は 1 つ（Oura・Insight Timer の再生画面）→ ホームの絵、レッスンの再生の操作（ゆっくり・まねして言う・もう一度）。
- データを文字で見せる（Trainline の運行表）→ 路線は番号・線・駅名の縦の運行表、しおりの時刻表。
- 大きな数字（Noom・WHOOP）→ 達成画面の続けた日数と今週の丸。
- 保存一覧（Places・Polarsteps）→ フレーズの場面は名画の正方形を横に送る。
- 使わない: 金融系の紫のグラデーション、光沢の 3D、マスコット、紙吹雪。

## 固定するもの（定数）
- 色: UI に差し色を置かない。色は絵から来る。
  - 白い面 `--paper` #FFFFFF / #141311、薄い面 `--wall` #F2F0EC / #201E1B、`--wall-2` #E8E5DF / #2A2824
  - 文字 `--ink` #1A1916 / #F1EDE4、`--ink-2` #3E3C37 / #D5CFC3、補助 `--muted` #66635B / #A8A296、区切り `--sep`
  - 壁 `--dark` #1B1A17、壁の上の文字 `--on-dark` #F4EFE4（象牙色）
  - 路線色はその人の印だけ（番号の丸・スタンプ）。正解 `--ok`・誤り `--ng`（色と文字の両方で示す）。SOS と緊急番号は `--ng`
- 文字
  - 和文: Hiragino Sans / Noto Sans JP。見出しは palt・字間 0、本文 0.02em。本文 16px、補助 14px 以上
  - 学ぶ文と数字: Jost。題だけ Bodoni Moda（正体、仏語の小さなラベルは斜体）
  - 大きさ: 14 / 15 / 16 / 18 / 20 / 22 / 24 / 34 / 48〜56（題）/ 120（達成の数字）
  - 大きな文字モードは html を 20px（広い画面は 21px）
- 余白: 画面の左右 20px（スマホ）、白い面の中身は最大 600px。区切りは 32px、節は 48px
- 角: 白い札 28px、面 16px、小さな面 12px、ボタンは丸
- 押せる所は 44px 以上、主なボタンは 52〜56px（大きな文字モードでは 56px）
- コントラスト: 壁の上の文字は 40 枚すべてで 4.5:1 以上（測った最小 5.2:1、下の「確かめ方」）

## 画面の組み方
- 各タブ: 壁（左に Bodoni の仏語の題と和文、右に小さく掛けた絵、下に解説札）→ 白い面。フレーズ = Béraud《La Pâtisserie Gloppe》、練習 = Fragonard《La Liseuse》、しおり = Monet《La Rue Montorgueil》、家族 = Renoir《Bal du moulin de la Galette》。
- ホーム: 次のレッスンの名画を画面幅いっぱい（上に「つぎの駅・出発まで」と駅名）→ 今日の一文と音声 → 墨のボタン → 今日の 3 つ（灰の面のリスト）→ わたしの路線（運行表、いまの駅の前後 5 駅、「すべて見る」で全駅）。旅行中は絵を小さめにして「今日の旅」を先に。
- レッスン: 上の壁に閉じる・進み具合・数と、その回の名画（問題の画面では小さく）→ 白い面に課題 → 下に固定のボタン。正解で絵がふっと寄る。
- 達成（レッスンの終わり）: 画面全体を壁にして、祝いの言葉、続けた日数の大きな数字、今週の丸、手に入れた名画、スタンプ（右上）、象牙色のボタン。
- 店員さんに見せる画面: 白い紙に大きな Jost の文字だけ。
- 広い画面（1024px 以上）: 左 11 : 右 9。左の壁は画面の高さで止まり（sticky）、絵を大きく掛ける。右は白い面で、上に文字だけのタブ。

## 絵
- 名画 40 枚（駅 15 枚＋レッスンごと a01〜a28）。すべてパブリックドメイン（Wikimedia Commons）。tools/make-photos.py が縮小し、data/photos.js に縦横・画家・作品名・年・出典を書く。レッスンと絵の対応は core.js の `LESSON_ART`。出典は設定の「絵の出典」。
- CSS 変数に入れる絵の url() は、style.css の場所から解決されてしまうので、`App.artUrl` でページからの絶対 URL にしてから入れる。
- 第 6 版の挿絵（assets/img/il/）は画面では使っていない（オフライン用の一覧には残る）。

## 確かめ方
- 画面: `python -m http.server 8771` で配信し、390px とデスクトップ幅（1440px）で見る。
- 壁の上の文字のコントラスト: 各絵で壁を作り、文字を隠して撮った画像の、文字の範囲の明るい側 95% の明るさと象牙色の比を出す（作業メモの contrast.cjs / contrast.py の方法）。陰（`.shade`）や壁の明るさを変えたら測り直す。

## 自由にするもの（変数）
- 各画面のレイアウト、絵の大きさ、演出

## 雰囲気の言葉
美術館の展示室・本物の名画・静か・上品・余白・家族で一緒に・パリの街を歩く
