# デザインの決まり（第 3 版）

## 目的と使う人
- 2027 年 2 月 23〜26 日のパリ旅行に行く家族 3 人（母・兄・弟）が、フランス語ほぼゼロから「旅で困らない」まで進む。
- 使う場面: 出発までの毎日 5〜10 分（家・通勤）、旅行中は指さし帳とお守り代わり（電波なしでも）。
- 母も使う: 文字を大きくできる、押せる所は大きく、迷わない一本道。

## コンセプト
**Ma ligne（わたしの路線）** — 家族それぞれが自分のメトロ路線に乗って、パリへ向かう。
駅＝レッスン。終点が « Paris »。同じ路線図の上に家族の現在地が小さな丸で並ぶ。

## モチーフ
- パリのメトロ駅の白い面取りタイル（carrelage biseauté）の壁。光は駅の蛍光灯のように均一で、影はタイルの目地程度に浅い。
- 色の出どころは RATP の路線色。1 人に 1 路線色（母・兄・弟で色が違う）、場面にも路線色を割り当てる。地は白タイル、文字は駅名標の濃紺。
- 形はメトロの路線図: 太さ 6px の線、駅は白抜きの丸、乗り換え駅は角丸の棒。カードは駅名標のホーロー板（角丸・薄い縁）。
- 情報の優先順位: 「次の駅（今日のレッスン）」がいちばん大きく、路線全体は背景として静かに続く。
- 動き: 電車の加速と減速（ease-in-out）。駅に着くと止まり、扉が左右に開いてレッスンが始まる。終わると 3 音の発車チャイム（任意・小さく）。跳ねない。
- 言葉: フランス語はやわらかいセリフ（Fraunces）で大きく、日本語は丸ゴシックで親しみやすく。

## 固定するもの（定数）
- 色の役割（ライト / ダーク）
  - 地 `--bg` 白タイル #F6F5F1 / 夜の駅 #0C1120
  - 面 `--surface` #FFFFFF / #151B2C、目地 `--hair` #E2E0D8 / #252D44
  - `--line` はその人の路線色。文字に使うときは `--line-ink`（ライト・ダークそれぞれで 4.5:1 以上になるよう JS が計算）
  - 文字 `--ink` 駅名標の濃紺 #14213D / #EEF1F8、補助 `--muted` #5D6680 / #9AA3BB
  - 主色 `--accent` = その人の路線色（下の 3 色から選ぶ）。押せる物・現在地・進み具合
  - 正解 #2E7D4F / 誤り #C2412D（路線色と明度でも区別する）
  - 人の路線色: ジョーンヌ（1 号線）#F2B700、ヴィオレ（4 号線）#9B2F8F、ブルー（2 号線）#1F5FAF、ヴェール（6 号線）#5FA772、オランジュ（5 号線）#E8822A
- 文字
  - フランス語: Fraunces（opsz 可変）。日本語本文: Zen Kaku Gothic New。日本語見出し: Zen Maru Gothic。数字・ラベル: Jost
  - サイズの段階（標準）: 12 / 14 / 16 / 20 / 26 / 34 / 48 / 72。大きな文字モードは 1.25 倍
  - 行間: 本文 1.7、見出し 1.3、フランス語の大きな文 1.25
- 余白の刻み: 4 の倍数（4, 8, 12, 16, 24, 32, 48）。画面の左右は 20px（スマホ）
- 角丸: カード 20px、ボタン 999px（丸）、小物 12px。影は 1 種類だけ（浅い）＋押したときに沈む
- 押せる所は 48px 以上（大きな文字モードでは 56px）

## 自由にするもの（変数）
- 各画面のレイアウト、路線図の描き方、レッスン内の見せ方、演出

## 雰囲気の言葉
やさしい・迷わない・旅に出る前のわくわく・家族で一緒に・本物のパリの街の手触り
